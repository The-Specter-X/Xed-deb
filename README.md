# Xed packaging for Debian

This repository contains the Debian packaging for [Linux Mint's Xed](https://github.com/linuxmint/xed). It targets upstream release **3.9.0** and Debian source version **3.9.0+ds-1**. The `+ds` repack omits the upstream `debian/` directory so that this repository provides the only packaging files.

The source builds `xed` (editor, built-in plugins and private library), `xed-common` (shared data, help and translations), and `xed-dev` (plugin development files). Installing `xed` pulls in `xed-common` automatically. Debug symbols are generated by debhelper.

## Prepare the source and build it

Use a fresh Debian unstable build VM with `devscripts`, `dpkg-dev`, `build-essential`, and the packages needed by `debian/control`. From this packaging repository:

```sh
uscan --download-current-version
mkdir -p ../xed-3.9.0+ds
tar -xf ../xed_3.9.0+ds.orig.tar.xz -C ../xed-3.9.0+ds --strip-components=1
cp -a debian ../xed-3.9.0+ds/
cd ../xed-3.9.0+ds
sudo apt build-dep .
dpkg-buildpackage -us -uc
lintian -i -I --pedantic ../xed_3.9.0+ds-1_*.changes
```

The desktop GUI test suite in upstream Meson uses dogtail and an interactive display. The package runs an installed-file and GObject introspection smoke test through `autopkgtest`; also open the built package in a Debian desktop VM and verify editing, saving, plugin loading, and a Wayland session before uploading.

## Salsa and mentors

The canonical packaging location in `debian/control` is `https://salsa.debian.org/Overseer/xed`. Create that project and push the packaging history there. Enable the standard Salsa CI template under **Settings → CI/CD → General pipelines** with path `debian/salsa-ci.yml`.

The Xed WNPP bug is [#830598](https://bugs.debian.org/830598) (currently RFP). Claim it as an ITP before requesting sponsorship. After all build, install, CI and copyright checks pass, change the changelog distribution from `UNRELEASED` to `unstable`, build and sign a source upload (`dpkg-buildpackage -S`), and upload that signed source to mentors.debian.net for sponsor review. GitHub and Salsa do not publish a package to Debian automatically.
